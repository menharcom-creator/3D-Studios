# 3D Studio
HTML/index.html = the 3D modeling app (Three.js r128). iOS/ = SwiftUI + WKWebView wrapper. The GitHub workflow builds an unsigned IPA.
Phase 1 tools: select, move, rotate (Y), scale, push/pull, rectangle, circle, line, eraser, 7 primitives, properties, materials, undo/redo, autosave, JSON import/export.
Not yet built: Phases 2-5 (Follow Me, booleans, textures, architecture, terrain, GLB/OBJ, scenes, AI). No app icon yet.
